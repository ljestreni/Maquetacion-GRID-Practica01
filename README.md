# MaquetacionGRID_Practica01

Proyecto de maquetación web responsive utilizando CSS Grid Layout.

## Descripción

Esta práctica replica el diseño de la web "Arc Raiders" pero implementando la tecnología CSS Grid Layout, permitiendo un control bidimensional preciso sobre la estructura de la página.

## Contenido

El proyecto cuenta con una estructura similar a la versión Flexbox pero construida con rejillas:

- Header, Aside, Main y Footer bien definidos semánticamente.
- Distribución de contenido en filas y columnas.
- Tarjetas de contenido alineadas mediante Grid.

## Desarrollo

Se ha utilizado `display: grid` en el contenedor principal y en las secciones internas. Se han definido `grid-template-columns` y `grid-template-rows` para establecer las áreas del diseño, aprovechando la potencia de Grid para alinear elementos complejos de forma sencilla.

## Despliegue

Este proyecto no está desplegado en un servidor público, ya que se trata de una práctica local. Para visualizarlo:

1.  Descarga el código o clona el repositorio.
2.  Abre el archivo `maquetacionGRID_Practica01.html` directamente en tu navegador favorito.
3.  Opcional: Si utilizas **Visual Studio Code**, puedes usar la extensión **Live Server** para iniciarlo en un servidor local y ver los cambios en tiempo real.\_
